# tools.openooda.org

Official website and documentation catalog for the **openOODA Tools** ecosystem ([https://tools.openooda.org](https://tools.openooda.org)).

> **"Two Faces, One Engine: Blistering native CLI speed for humans • Zero-leakage MCP for AI agents."**

## Overview

`openOODA-tools.github.io` is a lightweight, zero-external-dependency documentation site and package catalog for the openOODA tool suite. It provides interactive man pages, capability requirement breakdowns, installation instructions, and a 256-tool sovereign userland blueprint.

The portal features:
- **Dual Scrolling Marquee**: Seamlessly drifts released utilities and blueprint specs in dual rows with pause controls and reduced-motion support.
- **Hidden Gems**: A curated, snap-scrolling carousel highlighting battle-tested capability-bounded utilities.
- **Catalog Browser**: Real-time search (`Ctrl+K`), category filtering, status tabs (Released vs. Blueprint), Cards vs. Split view layouts, and quick-copy curl install snippets.
- **Multi-Theme Support**: Dark, Tokyo Night, Gruvbox, Catppuccin, Ethereal, and Light themes powered by the `oote` color taxonomy.
