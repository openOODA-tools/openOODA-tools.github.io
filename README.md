# tools.openooda.org

Official website and documentation catalog for the **openOODA Tools** ecosystem ([https://tools.openooda.org](https://tools.openooda.org)).

> **"Two Faces, One Engine: Blistering native CLI speed for humans • Zero-leakage MCP for AI agents."**

## Overview

`openOODA-tools.github.io` is a lightweight, zero-external-dependency documentation site and package catalog for the openOODA tool suite. It provides interactive man pages, capability requirement breakdowns, and installation instructions for capability-bounded CLI tools.

## Included Tools

- [**oogrep**](https://tools.openooda.org/oogrep/): Capability-bounded pattern search with real-time stream tokenization.
- [**oodiff**](https://tools.openooda.org/oodiff/): High-performance structured AST and text diffing engine.
- [**oojq**](https://tools.openooda.org/oojq/): Streaming JSON processor adhering to openOODA capability boundaries.
- [**oofind**](https://tools.openooda.org/oofind/): Capability-safe filesystem traverser and asset locator.
- [**oosh**](https://tools.openooda.org/oosh/): Sovereign interactive shell and capability mediator.
- [**ootail**](https://github.com/openOODA-tools/ootail): Capability-isolated log tailing and streaming auditor.
- [**oote**](https://github.com/openOODA-tools/oote): Terminal sovereign theming and styling engine.

## Deployment

Published automatically via GitHub Pages from the `main` branch with custom domain `tools.openooda.org` configured via Cloudflare DNS.
