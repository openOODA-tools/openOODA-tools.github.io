oo7z

7-Zip multi-format container unpacker and lister with AES-256 encryption and MCP surface.

v0.2.0 100% openOODA Zero Ambient Authority Zero Zip-Slip Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oo7z/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oo7z/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oo7z/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oo7z/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oo7z binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oo7z-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oo7z/uninstall.sh | bash

Usage & Features

oo7z -l archive.7z             # Inspect 7-Zip container header properties
oo7z -t archive.7z             # Test archive integrity and 7z signature
oo7z -x archive.7z -o /dest    # Safe traversal-resistant extract
oo7z --mcp                     # Launch MCP stdio server
