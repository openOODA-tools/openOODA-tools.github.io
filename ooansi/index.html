ooansi

ANSI terminal sequence generator with 16-color, 256-color, TrueColor, and text sanitizer.

v0.2.0 100% openOODA Zero Ambient Authority TrueColor RGB Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/ooansi/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/ooansi/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/ooansi/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/ooansi/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove ooansi binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI ooansi-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/ooansi/uninstall.sh | bash

Usage & Features

ooansi color red               # Output ANSI red sequence
ooansi color '#ff00aa'         # Output 24-bit TrueColor RGB sequence
ooansi style bold              # Output SGR bold directive
ooansi strip "$text"           # Strip all ANSI codes to clean text
ooansi reset                   # Output terminal formatting reset
ooansi --mcp                   # Launch MCP stdio server
