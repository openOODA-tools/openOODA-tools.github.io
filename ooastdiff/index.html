ooastdiff

Language-agnostic AST syntax-aware diffing tool with token LCS alignment, comment/whitespace insensitivity, and stdio MCP server.

v0.2.0 100% openOODA Zero Ambient Authority Syntax-Aware LCS Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/ooastdiff/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/ooastdiff/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/ooastdiff/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/ooastdiff/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove ooastdiff binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI ooastdiff-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/ooastdiff/uninstall.sh | bash

Usage & Features

ooastdiff file1.oo file2.oo                       # Compare two files ignoring cosmetic changes
ooastdiff --tokens file.oo                        # Lex source and output token stream
ooastdiff --tokens --json file.oo                 # Output tokens formatted as JSON
ooastdiff --json file1.oo file2.oo                # Output structural diff report as JSON
ooastdiff --mcp                                   # Launch MCP stdio server
