ooattest

Attests system state and measured boot hashes using TPM2 hardware security chips.

v0.2.0 100% openOODA Zero Ambient Authority TPM2 Hardware Security Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/ooattest/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/ooattest/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/ooattest/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/ooattest/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove ooattest binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI ooattest-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/ooattest/uninstall.sh | bash

Usage & Features

ooattest --pcrs                                  # Display measured PCR register table
ooattest --status                                # Query TPM2 hardware chip presence
ooattest --pcr 7                                 # Inspect Secure Boot PCR 7
ooattest --verify golden_baseline.txt            # Audit PCRs against reference manifest
ooattest --json                                  # Output PCR dump as JSON
ooattest --mcp                                   # Launch MCP stdio server
