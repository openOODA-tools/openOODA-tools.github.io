Usage & Features

oob3sum file.tar.gz                              # Compute 256-bit BLAKE3 digest
oob3sum --tag file.iso                           # Emit BSD-style checksum
oob3sum -c checksums.b3                          # Verify checksum manifest
oob3sum --json firmware.bin                      # Output structured JSON record
oob3sum --mcp                                    # Launch streaming MCP stdio server
