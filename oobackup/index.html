oobackup

Point-in-time snapshot coordinator creating deduplicated, content-addressed file trees.

v0.2.0 100% openOODA Zero Ambient Authority Merkle Snapshots Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oobackup/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oobackup/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oobackup/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oobackup/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oobackup binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oobackup-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oobackup/uninstall.sh | bash

Why Sovereign oobackup?

Dimension Legacy rsync / restic openOODA oobackup
ArchitectureAmbient execution with full root filesystem accessZero ambient authority, capability-bounded FsRead/FsWrite tokens
Integrity ValidationAd-hoc checksums or large external state databasesContent-addressed Merkle tree hash manifests per snapshot generation
DifferentialsComplex delta transfers requiring dedicated daemonsIntegrated 3-way differential engine (added, removed, modified, unchanged)
AI AgentsNo agent interfaceMCP stdio tools: backup_create, backup_list, backup_verify, backup_diff, backup_stats

Usage & Features

oobackup --init --repo ./backup.index            # Initialize empty repository
oobackup --repo ./backup.index src/ docs/        # Create snapshot of target files
oobackup --repo ./backup.index --list            # Tabulate stored repository snapshots
oobackup --repo ./backup.index --verify snap-01  # Audit file integrity against disk
oobackup --repo ./backup.index --diff s1 s2      # Compute three-way snapshot differential
oobackup --mcp                                   # Launch streaming MCP stdio server
