oobanner

Renders stylized ASCII art banners, typography, and logos in the terminal.

v0.2.0 100% openOODA Zero Ambient Authority FIGLET Typography Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oobanner/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oobanner/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oobanner/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oobanner/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oobanner binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oobanner-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oobanner/uninstall.sh | bash

Usage & Features

oobanner "SYSTEM OK"                             # Render 5-line standard typography
oobanner -f block "WARNING"                      # Render compact 3-line block banner
oobanner -b double -a center "OPENOODA"          # Double border frame with center alignment
oobanner -b star -c cyan "AGENTS"                # Cyan star marquee frame
oobanner --json "METRICS"                        # Output structured JSON line matrix
oobanner --mcp                                   # Launch streaming MCP stdio server
