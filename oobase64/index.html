Usage & Features

oobase64 "Hello World"                           # Standard Base64 encoding
oobase64 -d "SGVsbG8gV29ybGQ="                   # Decode Base64 string
oobase64 -u "Hello World"                        # URL-safe alphabet encoding
oobase64 --no-padding "Hello World"              # Encode omitting padding equal signs
oobase64 -w 76 document.bin                      # Wrap encoded lines at 76 characters
oobase64 --json "Hello World"                    # Output structured JSON envelope
oobase64 --mcp                                   # Launch streaming MCP stdio server
