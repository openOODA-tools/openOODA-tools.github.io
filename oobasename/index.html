oobasename

Strips directory prefixes and optional file extensions from path strings.

v0.2.0 100% openOODA Zero Ambient Authority POSIX Compatible Model Context Protocol

Usage & Features

oobasename /usr/bin/sort                         # Emits 'sort'
oobasename /usr/lib/                             # Emits 'lib' (trailing slash stripped)
oobasename include/stdio.h .h                    # Emits 'stdio' (suffix removed)
oobasename -s .h /usr/include/stdio.h            # Suffix flag
oobasename -a /usr/bin/sort /usr/bin/find        # Multiple path inputs
oobasename -z -a file1.txt file2.txt             # NUL-delimited stream
oobasename --json /usr/bin/sort                  # Output structured JSON
oobasename --mcp                                 # Launch streaming MCP stdio server
