oobindiff

Structural binary differ identifying patch blocks and byte sequence displacements.

v0.2.0 100% openOODA Zero Ambient Authority Binary Comparison Model Context Protocol

Usage & Features

oobindiff original.bin patched.bin               # Detailed byte-by-byte mutation rows
oobindiff -s firmware_v1.bin firmware_v2.bin     # Summary metrics and similarity percentage only
oobindiff -u kernel.old kernel.new               # Contiguous difference hunks overview
oobindiff -o 0x1000 -n 50 a.out b.out            # Compare byte window with offset and row limit
oobindiff --json file1.dat file2.dat             # Output machine-readable JSON telemetry
oobindiff --mcp                                  # Run Model Context Protocol stdio server
