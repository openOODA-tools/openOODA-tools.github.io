ooborder

Wraps stdin or file text blocks inside configurable border frames with titles and alignment.

v0.2.0 100% openOODA Zero Ambient Authority Text Formatting Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/ooborder/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/ooborder/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/ooborder/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/ooborder/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove ooborder binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI ooborder-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/ooborder/uninstall.sh | bash

Why Sovereign ooborder?

Dimension Legacy boxes / text-box scripts openOODA ooborder
ArchitectureAmbient execution with unmanaged C buffers or Perl dependenciesZero ambient authority, capability-bounded explicit tokens
Style PresetsHardcoded or external config filesEmbedded native styles: single, double, rounded, thick, ascii, block
Alignment & PaddingComplex manual indentation flagsParametric padding margins with left, center, right text justification
AI AgentsNo agent interfaceStreaming MCP stdio server: border_wrap, border_styles, border_stats

Usage & Features

echo "Hello openOODA" | ooborder                         # Default rounded border frame
echo "ALERT: CPU OVERHEAT" | ooborder -s thick -t "WARN"  # Thick border with title banner
ooborder -s double -t "Status" --align center report.txt  # Centered text in double border
ooborder --json message.txt                               # Output machine-readable JSON structure
ooborder --mcp                                            # Run Model Context Protocol stdio server
