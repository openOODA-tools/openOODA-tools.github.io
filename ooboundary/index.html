Hardware enforced kernel netfilter hook restricting agent sockets to allowed IPs and CIDRs.

Usage & Features

ooboundary -P isolated                                  # Complete network isolation (no loopback, drop all)
ooboundary -P local                                     # Loopback only (127.0.0.1/8, ::1)
ooboundary -a "10.0.0.0/8" -p 443                       # Whitelist private subnet on HTTPS
ooboundary --format systemd -a "1.1.1.1/32"             # Generate systemd [Service] network drop-in
ooboundary --format nftables -a "192.168.1.1" -p 53     # Generate kernel nftables egress filter table
ooboundary --audit -a "10.0.0.1"                        # Audit destination CIDR against exfiltration risks
ooboundary --mcp                                        # Run Model Context Protocol stdio server
