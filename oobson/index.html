oobson

Binary JSON encoder and decoder with bson-to-json streaming converters and structural inspector.

v0.2.0 100% openOODA Zero Ambient Authority BSON Codec Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oobson/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oobson/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oobson/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oobson/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oobson binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oobson-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oobson/uninstall.sh | bash

Why Sovereign oobson?

CapabilitiesUnrestricted ambient filesystem and network accessCapability-bounded (&FsReadCap, &ProcessCap, &McpCap)
InspectionOpaque hex dumps or unformatted stdoutStructured type inspector with element offsets and sizes
AI AgentsNo agent interfaceStreaming MCP stdio server: bson_decode, bson_encode, bson_inspect, bson_stats

Usage & Features

oobson sample.bson                                     # Inspect BSON document structure and fields
oobson --json sample.bson                              # Convert BSON document to formatted JSON
oobson --to bson '{"name":"agent","count":42}'         # Encode JSON object to BSON hex payload
oobson --inspect sample.bson                           # Detailed element breakdown with byte offsets
oobson --mcp                                           # Run Model Context Protocol stdio server
