oobzip2

Burrows-Wheeler block sorting text compression engine with integrity checks and streaming MCP server.

v0.2.0 100% openOODA Zero Ambient Authority BWT Compression Model Context Protocol

Usage & Features

oobzip2 sample.txt                                     # Compress text using BWT + MTF + RLE + CRC32
oobzip2 -d "BZh9:..."                                  # Decompress bzip2 payload back to text
oobzip2 -t "BZh9:..."                                  # Test and verify CRC-32 stream integrity
oobzip2 -i "BZh9:..."                                  # Inspect container header and block size
oobzip2 --bwt "BANANA"                                 # Perform raw Burrows-Wheeler Transform
oobzip2 --json sample.txt                              # Output structured compression metrics as JSON
oobzip2 --mcp                                          # Run Model Context Protocol stdio server
