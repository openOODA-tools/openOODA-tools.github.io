oocat

Capability-bounded syntax file viewer and pager with oote themes, line ranges, and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority Syntax Lexers Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oocat/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oocat/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oocat/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oocat/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oocat binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oocat-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oocat/uninstall.sh | bash

Why Sovereign oocat?

Dimension Conventional Alternatives openOODA oocat
SecurityAmbient filesystem read accessBounded by &FsReadCap tokens
HighlightingExternal regex enginesPure openOODA lexers (oo, sh, c, json, py, md)
ThemingHardcoded color palettesSemantic token styling from ~/.openooda/theme.oot
AI AgentsNo agent interfaceMCP stdio tools: oocat_view, oocat_highlight

Usage & Features

oocat main.oo                  # View file with syntax highlights & line numbers
oocat -r 10:50 config.ini      # View bounded line range window
git diff | oocat -             # Stream and format diff from stdin
oocat --mcp                    # Launch MCP stdio server
