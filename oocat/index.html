oocat

Sovereign syntax-highlighting file viewer and pager with oote palettes and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority oote Syntax Tokens Range Windowing Model Context Protocol

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/oocat/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/oocat/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/oocat/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/oocat/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove oocat binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
oocat-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/oocat/uninstall.sh | bash

# 3. Dry-run preview
oocat-uninstall --dry-run

Try it

oocat main.oo                         # View file with headers, line numbers & syntax
oocat main.oo -r 10:30                # View bounded line range
oocat main.oo --style plain           # Raw cat output without gutters
git diff | oocat - --style numbers    # Pipe from standard input
oocat --mcp                           # Launch MCP stdio server
