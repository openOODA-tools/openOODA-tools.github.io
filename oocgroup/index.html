oocgroup

Creates and configures cgroup v2 resource limits for memory, cpu, and io controllers with systemd drop-in generation.

v0.2.0 100% openOODA Zero Ambient Authority Cgroup v2 / Systemd Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oocgroup/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oocgroup/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oocgroup/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oocgroup/install.sh | bash -s -- --pkgbuild

Usage & Features

oocgroup                                                  # Inspect current process cgroup v2 and active controllers
oocgroup -a                                               # Audit cgroup security delegation, unconstrained limits, and OOM risks
oocgroup -s -m 2G -c 50% --pids 1000 -u worker            # Synthesize systemd drop-in unit with resource constraints
oocgroup -p /sys/fs/cgroup/user.slice                     # Inspect target slice or cgroup directory
oocgroup -t                                               # Render visual cgroup hierarchy tree
oocgroup --demo                                           # Run in demo mode with synthetic cgroup hierarchy
oocgroup --json                                           # Output structured JSON telemetry
oocgroup --mcp                                            # Run Model Context Protocol stdio server
