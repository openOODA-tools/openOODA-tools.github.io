oocgroupv2

Visualizes the active cgroup v2 slice hierarchy, Pressure Stall Information (PSI), and sibling resource shares.

v0.2.0 100% openOODA Zero Ambient Authority cgroup v2 / PSI Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oocgroupv2/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oocgroupv2/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oocgroupv2/install.sh | bash -s -- --pkgbuild

Remove oocgroupv2 binaries, package registrations, and symlinks at any time:

Why Sovereign oocgroupv2?

Usage & Features

oocgroupv2                                                # Render unified cgroup v2 slice hierarchy tree
oocgroupv2 --psi                                          # Display Pressure Stall Information (PSI) panel
oocgroupv2 --shares                                       # Calculate sibling CPU weight shares and allocations
oocgroupv2 -s system --procs                              # Inspect system.slice with per-node task counts
oocgroupv2 --summary                                      # High-level overview of slices, tasks, and CPU pressure
oocgroupv2 --demo                                         # Run in demo mode with synthetic server hierarchy
oocgroupv2 --json                                         # Output structured JSON telemetry
oocgroupv2 --mcp                                          # Run Model Context Protocol stdio server
