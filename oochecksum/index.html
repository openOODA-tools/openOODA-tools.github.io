oochecksum

Unified integrity checking utility verifying BSD and GNU style checksum manifests.

v0.2.0 100% openOODA Zero Ambient Authority BSD & GNU Manifests Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oochecksum/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oochecksum/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oochecksum/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oochecksum/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oochecksum binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oochecksum-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oochecksum/uninstall.sh | bash

Why Sovereign oochecksum?

Dimension Legacy sha256sum / md5sum / shasum openOODA oochecksum
Unified FormatsFragile bash pipelines, incompatible BSD vs GNU syntaxSeamless parsing of both BSD and GNU manifest conventions
Algorithm AgilitySeparate binaries for sha1sum, sha256sum, sha512sum, md5sumSingle unified binary with auto-detection across algorithms
Negative-TrustUnbounded filesystem access and shell expansion vulnerabilitiesExplicit capability tokens (&FsReadCap, &McpCap)
AI AgentsNo agent interfaceStreaming MCP stdio server: checksum_verify, generate, detect, audit, hash

Usage & Features

oochecksum -c checksums.txt                               # Verify checksums from manifest file
oochecksum -c checksums.txt --quiet                       # Suppress OK messages, reporting only failures
oochecksum -c checksums.txt --status                      # Silent execution, exit code indicates verification result
oochecksum --tag file1.tar.gz file2.deb                   # Generate BSD-style checksum manifest
oochecksum file1.tar.gz file2.deb                         # Generate GNU-style checksum manifest
oochecksum --demo                                         # Run verification against sample embedded manifest
oochecksum --demo --json                                  # Output structured JSON telemetry
oochecksum --mcp                                          # Run Model Context Protocol stdio server
