oochown

Changes user and group ownership of filesystem objects with systemd-tmpfiles declarative synthesis.

v0.2.0 100% openOODA Zero Ambient Authority systemd-tmpfiles Native Model Context Protocol

Usage & Features

oochown alice:alice /home/alice/data                      # Change user and group
oochown :staff /srv/shared                                # Change group only
oochown alice: /home/alice/project                        # Change user and reset to login group
oochown -R www-data:www-data /var/www/html                # Recursively change ownership
oochown --reference=/etc/shadow /backup/shadow            # Adopt ownership of reference file
oochown --dry-run alice:alice /etc/app.conf               # Preview changes without modifying filesystem
oochown --tmpfiles www-data:www-data /var/www/html        # Generate declarative systemd-tmpfiles rule
oochown --demo                                            # Run demonstration with synthetic fixtures
oochown --demo --json                                     # Output structured JSON telemetry
oochown --mcp                                             # Run Model Context Protocol stdio server
