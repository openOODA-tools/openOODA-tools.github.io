oochroot

Sets up capability-bounded root filesystem jails with systemd service confinement synthesis.

v0.2.0 100% openOODA Zero Ambient Authority systemd Confinement Native Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oochroot/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oochroot/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oochroot/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oochroot/install.sh | bash -s -- --pkgbuild

Why Sovereign oochroot?

Dimension Legacy GNU chroot openOODA oochroot

Usage & Features

oochroot /var/lib/jails/alpine                                   # Enter jail with default shell
oochroot -u sandbox:sandbox /var/lib/jails/app /bin/sh           # Jail with unprivileged userspec
oochroot --mount-api-vfs /var/lib/jails/app /bin/sh              # Plan/mount /proc, /sys, /dev
oochroot --systemd /var/lib/jails/app /usr/bin/app               # Synthesize declarative systemd service unit
oochroot --audit /var/lib/jails/app                              # Audit jail for vulnerabilities
oochroot --dry-run /var/lib/jails/app                            # Preview execution without filesystem mutations
oochroot --demo                                                  # Run demonstration scenario with synthetic fixtures
oochroot --demo --json                                           # Output structured JSON telemetry
oochroot --mcp                                                   # Run Model Context Protocol stdio server
