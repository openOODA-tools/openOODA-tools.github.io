ooclock

Sovereign TUI digital matrix clock, stopwatch, and Pomodoro focus timer with circadian mascot moods and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority Matrix Typography Circadian Mascot Model Context Protocol

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/ooclock/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/ooclock/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/ooclock/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/ooclock/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove ooclock binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
ooclock-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/ooclock/uninstall.sh | bash

# 3. Dry-run preview
ooclock-uninstall --dry-run
