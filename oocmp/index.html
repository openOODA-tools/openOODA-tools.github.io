oocmp

Instant byte-by-byte file comparison reporting first byte difference, line count, and octal diffs.

v0.2.0 100% openOODA Zero Ambient Authority POSIX cmp Native Model Context Protocol

Usage & Features

oocmp file1.bin file2.bin                                        # Compare files byte-by-byte
oocmp -l file1.bin file2.bin                                     # Verbose listing of byte offsets and octal values
oocmp -b file1.bin file2.bin                                     # Print differing bytes alongside byte offset
oocmp -i 1024:2048 file1.bin file2.bin                           # Skip initial bytes on file1 and file2
oocmp -n 512 file1.bin file2.bin                                 # Compare at most 512 bytes
oocmp -s file1.bin file2.bin                                     # Silent mode (exit code 0 if equal, 1 if differ)
oocmp --demo                                                     # Run demonstration comparison scenarios
oocmp --demo --json                                              # Output structured JSON telemetry
oocmp --mcp                                                      # Run Model Context Protocol stdio server
