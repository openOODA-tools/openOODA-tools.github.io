oocolor

Multi-space color converter, TrueColor previewer, and WCAG 2.1 contrast auditor.

v0.2.0 100% openOODA Zero Ambient Authority TrueColor & WCAG 2.1 Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oocolor/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oocolor/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oocolor/install.sh | bash -s -- --pkgbuild

Usage & Features

oocolor "#3498DB"                                                 # Display formatted color card with TrueColor swatch
oocolor -r "#3498DB"                                              # Convert HEX to RGB representation
oocolor -s "#00FF00"                                              # Convert to HSL representation
oocolor -c "coral"                                                # Convert named color to CMYK
oocolor -a "white"                                                # Compute ANSI 256 index
oocolor -p "#FF5733"                                              # Render 24-bit TrueColor terminal swatch
oocolor "#FFFFFF" --contrast "#000000"                            # WCAG 2.1 contrast ratio and AA/AAA report
oocolor "#3498DB" --palette tints --preview                       # Generate 5-step tint palette swatches
oocolor --demo                                                    # Run chromatic demonstration matrix
oocolor --json "#3498DB"                                          # Output structured JSON Lines telemetry
oocolor --mcp                                                     # Run Model Context Protocol stdio server
