oocomm

Compare two sorted files line by line to produce unique and common lines with column suppression.

v0.2.0 100% openOODA Zero Ambient Authority POSIX comm Native Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oocomm/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oocomm/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oocomm/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oocomm/install.sh | bash -s -- --pkgbuild

Usage & Features

oocomm file1.txt file2.txt                                        # Three-column comparison (Col 1: unique1, Col 2: unique2, Col 3: common)
oocomm -12 file1.txt file2.txt                                    # Show only lines common to both files
oocomm -23 file1.txt file2.txt                                    # Show only lines unique to file 1
oocomm -3 file1.txt file2.txt                                     # Show lines unique to either file (symmetric difference)
oocomm --output-delimiter="," file1.txt file2.txt                 # Use custom delimiter between columns
oocomm --total file1.txt file2.txt                                # Output summary line with category counts
oocomm --inspect file1.txt file2.txt                              # Display visual inspection breakdown
oocomm --demo                                                     # Run demonstration with synthetic sorted fruit datasets
oocomm --demo --json                                              # Output structured JSON telemetry
oocomm --mcp                                                      # Run Model Context Protocol stdio server
