oocp

Zero-copy clone-capable file and directory copier using io_uring, copy_file_range, and pure openOODA.

v0.2.0 100% openOODA Zero Ambient Authority POSIX cp Native Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oocp/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oocp/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oocp/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oocp/install.sh | bash -s -- --pkgbuild

Usage & Features

oocp source.txt target.txt                                        # Copy single file
oocp -r src_dir/ dest_dir/                                        # Recursively copy directory tree
oocp -b source.txt existing.txt                                   # Create backup copy with '~' suffix
oocp -f source.txt target.txt                                     # Force remove existing destination file
oocp -n source.txt target.txt                                     # No-clobber: do not overwrite existing file
oocp --reflink=always bigfile.bin clone.bin                       # Instant zero-copy CoW reflink cloning
oocp -s source.txt symlink.txt                                    # Create symbolic link instead of copying
oocp -l source.txt hardlink.txt                                   # Create hard link instead of copying
oocp --demo                                                       # Run synthetic replication telemetry demo
oocp --demo --json                                                # Output structured JSON telemetry
oocp --mcp                                                        # Run Model Context Protocol stdio server
