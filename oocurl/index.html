oocurl

Sovereign capability-bounded HTTP and API client with syntax-highlighted responses, oote palettes, and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority TcpCap Secured HTTP/1.1 Engine Model Context Protocol

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/oocurl/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/oocurl/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/oocurl/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/oocurl/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove oocurl binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
oocurl-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/oocurl/uninstall.sh | bash

# 3. Dry-run preview
oocurl-uninstall --dry-run

Try it

oocurl http://127.0.0.1:8080/api/status          # Capability-bounded GET request
oocurl -i http://127.0.0.1:8080/health          # Print status headers and body
oocurl -X POST -d '{"q":"val"}' http://host/api # POST JSON payload
oocurl -o output.json http://host/data          # Safe file download
oocurl --mcp                                    # Launch MCP stdio server
