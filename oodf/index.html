oodf

POSIX-compliant disk space and mount point storage inspector with block and inode telemetry in pure openOODA.

v0.2.0 100% openOODA Zero Ambient Authority POSIX df Parity Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oodf/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oodf/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oodf/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oodf/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oodf binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oodf-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oodf/uninstall.sh | bash

Usage & Features

oodf -h                                                          # Human-readable block storage capacity
oodf -i -t btrfs                                                 # Inode metrics on btrfs filesystems
oodf -h --total                                                  # Grand total capacity row across all mounts
oodf -h -x tmpfs                                                 # Exclude virtual memory filesystems
oodf -j                                                          # Emit structured JSON telemetry
oodf -D --theme=ocean                                            # Synthetic cluster storage showcase
oodf /home                                                       # Target specific mount path
oodf --mcp                                                       # Launch Model Context Protocol stdio server
