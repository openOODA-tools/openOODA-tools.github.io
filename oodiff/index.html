oodiff

Capability-bounded file and directory comparison for the openOODA era.

v0.1.0 100% openOODA Myers LCS Parity vs GNU diff

Install

curl -fsSL https://openooda-tools.github.io/oodiff/install.sh | bash

Zero dependencies. Installs native standalone binary to /usr/local/bin (or ~/.local/bin).

Why not just diff?

CheckGNU diffoodiff
Hunk format & patch compatibilityyesbyte-identical hunk parity
Exit codes (0 identical, 1 diffs, 2 error)yesyes
Trailing newline discipline (\ No newline at end of file)yesyes
Recursive directory trees (-r)yesyes
Agent hookup (MCP stdio server)noyes (diff_files, diff_dirs)
Capability-based securitynozero ambient filesystem authority

Try it

oodiff file_a.txt file_b.txt
oodiff -r src_v1/ src_v2/
oodiff --mcp   # spawn as Model Context Protocol server
