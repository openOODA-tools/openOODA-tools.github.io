oodiff

Capability-bounded file and directory comparison for the openOODA era.

v0.2.0 100% openOODA Myers LCS GNU diff Parity MCP Native

Install

curl -fsSL https://openooda-tools.github.io/oodiff/install.sh | bash

Zero dependencies. Installs native standalone binary to /usr/local/bin (or ~/.local/bin).

Try it

oodiff file_a.txt file_b.txt              # POSIX normal diff (default)
oodiff -u file_a.txt file_b.txt           # Unified diff
oodiff -b -B file_a.txt file_b.txt        # Ignore space & blank line changes
oodiff -r -N src_v1/ src_v2/              # Recursive directory diff
oodiff --mcp                              # Model Context Protocol stdio server
