Usage & Features

oodiff3 mine.txt base.txt yours.txt                                       # Standard diff3 format
oodiff3 -m mine.txt base.txt yours.txt                                    # 3-way merge with conflict markers
oodiff3 -m -L "MINE" -L "BASE" -L "YOURS" mine.txt base.txt yours.txt     # Custom operand labels
oodiff3 -e mine.txt base.txt yours.txt                                    # Generate ed script
oodiff3 -j mine.txt base.txt yours.txt                                    # JSON Lines stream
oodiff3 -D                                                                # Synthetic reconciliation showcase
oodiff3 --mcp                                                             # Launch Model Context Protocol server
