Usage & Features

oodig google.com A                                                        # Standard DNS query
oodig @8.8.8.8 google.com AAAA +short                                     # Direct nameserver query with concise answer
oodig -x 142.251.35.78                                                    # Reverse DNS lookup (in-addr.arpa)
oodig google.com +trace                                                   # Delegation trace from root to authoritative
oodig google.com MX -j                                                    # Structured JSON output
oodig -D                                                                  # Multi-record synthetic showcase
oodig --mcp                                                               # Launch Model Context Protocol server
