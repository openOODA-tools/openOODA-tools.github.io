Usage & Features

oodu -h                                                    # Human-readable recursive capacity
oodu -sh /var/log                                          # Concise summary total for directory
oodu -d 2 /usr/lib                                         # Depth-limited directory tree accounting
oodu -a /var/log                                           # Include all files, not just directories
oodu --inodes /var/log                                     # Inspect inode counts instead of byte weights
oodu --top 5 /home                                         # Visual breakdown of top 5 disk space hogs
oodu -j /var/log                                           # Structured JSON Lines stream
oodu -D                                                    # Synthetic multi-directory demonstration showcase
oodu --mcp                                                 # Launch Model Context Protocol server
