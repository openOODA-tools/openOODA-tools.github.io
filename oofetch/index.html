oofetch

Sovereign system fetch and environment showcase with oote swatches and MCP stdio surface.

v0.1.0 100% openOODA Zero Ambient Authority oote Swatches Model Context Protocol Sub-millisecond

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/oofetch/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/oofetch/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/oofetch/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/oofetch/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove oofetch binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
oofetch-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/oofetch/uninstall.sh | bash

# 3. Dry-run preview
oofetch-uninstall --dry-run
