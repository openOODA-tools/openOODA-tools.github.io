oofigure

Sovereign Unicode box-drawing tables, callouts, and code borders in pure openOODA.

v0.2.0 100% openOODA Zero Ambient Authority Box Drawing Standards Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oofigure/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oofigure/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oofigure/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oofigure/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oofigure binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oofigure-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oofigure/uninstall.sh | bash

Usage & Features

oofigure "System Initialized"                             # Default rounded box
oofigure -s double -t "Kernel" "Memory Check Passed"       # Double border with title
oofigure -s heavy "Critical Warning"                       # Heavy/bold border
oofigure -s ascii "Plain text frame"                       # Pure ASCII +--+ border
oofigure -c tip "Use capability tokens for isolation"      # GFM tip callout box
oofigure -c warning "Direct disk writes prohibited"        # GFM warning callout box
oofigure --numbers file.oo                                 # Prepend line numbers in panel
oofigure -j "Payload content"                              # Structured JSON geometry
oofigure -D                                                # Interactive multi-style showcase
oofigure --mcp                                             # Launch Model Context Protocol stdio server
