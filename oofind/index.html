oofind

Fast capability-bounded directory traversal with glob matching, type filtering, -print0, and MCP surface.

v0.2.1 100% openOODA Zero Ambient Authority Streaming JSON Lines Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oofind/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oofind/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oofind/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oofind/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oofind binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oofind-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oofind/uninstall.sh | bash

Usage & Features

oofind . -name "*.oo"          # Find files matching glob pattern
oofind /path -type d           # Find directories only
oofind . -name "*.log" -print0 | xargs -0 rm # Safe null-delimited piping
oofind --mcp                   # Launch MCP stdio server
