oofind

Capability-bounded file finding utility for the openOODA era.

v0.2.0 100% openOODA Zero Ambient Authority JSON Streaming MCP Native

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/oofind/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/oofind/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/oofind/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/oofind/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Try it

oofind . -name "*.oo"                     # Glob pattern matching
oofind src -type f -e txt                 # Filter regular files with extension
oofind . -maxdepth 2 -name "Makefile"     # Bounded depth traversal
oofind /var/log -type f -size +10M        # Size filtering
oofind src -name "*.oo" -print0 | xargs -0 wc -l  # Pipeline integration
oofind . -name "*.oo" --json              # JSON Lines output
oofind --mcp                              # Model Context Protocol stdio server
