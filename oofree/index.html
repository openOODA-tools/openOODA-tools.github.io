oofree(1) — Sovereign openOODA Memory Auditor & Telemetry Engine

Displays total, free, cached, buffers, and swap memory with unit conversions without ambient authority.

100% openOODA Zero Ambient Authority Procfs Telemetry & Unit Scaling Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oofree/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oofree/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oofree/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oofree/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oofree binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oofree-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oofree/uninstall.sh | bash

Why Sovereign oofree?

Dimension Legacy Tools (procps free) openOODA oofree
ArchitectureLegacy C codebase with unbounded ambient root/disk capabilityPure native openOODA with explicit capability tokens (&FsReadCap, &ProcessCap, &EnvCap)
Derived AccountingHistorical divergence on buff/cache vs slab reclaimableStandardized procps 3.3.10+ accounting accurately parsing Buffers, Cached, and SReclaimable
Unit ScalingBasic integer truncationPrecise powers of 1024 (-h, -k, -m, -g, --tera) and decimal powers of 1000 (--si, --kilo, --mega, --giga)
AI AgentsNo structured telemetry or agent protocolsStreaming MCP JSON-RPC 2.0 stdio server with memory metrics, swap stats, and pressure risk analysis

Usage & Features

oofree                                         # Standard memory table in kibibytes
oofree -h                                      # Human-readable auto-scaling (powers of 1024)
oofree -m                                      # Display values in mebibytes
oofree -w                                      # Wide output (separate buffers and cache)
oofree -t                                      # Add aggregate Total line (RAM + swap)
oofree -j                                      # Output structured JSON metrics
oofree -D                                      # Interactive multi-scenario memory showcase
oofree --mcp                                   # Launch Model Context Protocol stdio server
