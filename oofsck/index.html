oofsck(1) — Sovereign openOODA Filesystem Consistency Verifier

Audits superblock integrity, backup geometry, and inode allocation without ambient root authority.

100% openOODA Zero Ambient Authority Superblock & Inode Auditing Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oofsck/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oofsck/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oofsck/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oofsck/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oofsck binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oofsck-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oofsck/uninstall.sh | bash

Why Sovereign oofsck?

Dimension Legacy Tools (e2fsck / fsck) openOODA oofsck
ArchitectureMonolithic legacy C with ambient root and direct raw disk mutationsPure native openOODA with explicit capability tokens (&FsReadCap, &ProcessCap, &EnvCap)
Superblock AuditingOpaque binary inspection or invasive repair promptsStructured verification of magic numbers, block size, inode counts, and journal states
Backup GeometryManual calculation of sparse superblock block groupsAutomated discovery and validation across sparse groups (3, 5, 7, 9, 25, 49)
AI AgentsUnparseable terminal prompts and non-zero interactive locksStreaming MCP JSON-RPC 2.0 stdio server with superblock, inode, and partition health queries

Usage & Features

oofsck /dev/sda1                               # Audit partition filesystem integrity
oofsck -v /dev/sda1                            # Verbose inspection with alternate superblocks
oofsck -n /dev/sda1                            # Non-destructive read-only safety audit
oofsck -f /dev/sda1                            # Force complete verification scan
oofsck -j /dev/sda1                            # Machine-readable JSON integrity report
oofsck -D                                      # Interactive multi-scenario filesystem showcase
oofsck --mcp                                   # Launch Model Context Protocol stdio server
