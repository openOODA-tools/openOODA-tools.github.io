oogitdiff(1) — Sovereign openOODA Git Tree Differ & Delta Engine

Compares working tree vs commit objects and index cache without ambient git porcelain.

100% openOODA Zero Ambient Authority Object Store & Diffstat Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oogitdiff/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oogitdiff/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oogitdiff/install.sh | bash -s -- --pkgbuild

Remove oogitdiff binaries, package registrations, and symlinks at any time:

Usage & Features

oogitdiff                                      # Generate unified diff for working tree changes
oogitdiff --staged                             # View changes staged in the index
oogitdiff --stat                               # Generate diffstat table with +/- histogram bars
oogitdiff -s                                   # Name-status listing (M, A, D, ?)
oogitdiff -j                                   # Machine-readable JSON telemetry
oogitdiff -D                                   # Interactive multi-scenario repository showcase
oogitdiff --mcp                                # Launch Model Context Protocol stdio server
