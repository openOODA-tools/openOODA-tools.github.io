oogradient(1) — Sovereign openOODA TrueColor Gradient Interpolation Engine

Applies smooth TrueColor color gradient interpolation across lines of text.

100% openOODA Zero Ambient Authority TrueColor Palettes Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oogradient/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oogradient/install.sh | bash -s -- --pkgbuild

Why Sovereign oogradient?

Dimension Legacy Tools (lolcat / external python scripts) openOODA oogradient
ArchitectureRuby/Python runtime overhead or non-reproducible scriptsPure native openOODA with explicit capability tokens (&FsReadCap, &ProcessCap, &EnvCap)
Color MathematicsFixed rainbow cycle or approximate 256-color lookupsFull 24-bit TrueColor linear interpolation with 8 multi-stop curated palettes and custom hex bounds
TelemetryRaw terminal stdout onlyDual output mode: terminal ANSI truecolor sequences or structured JSON telemetry (-j)
AI AgentsNo agent interface for terminal colorizationStreaming MCP JSON-RPC 2.0 stdio server providing 5 tools (apply, interpolate, presets, preview, demo)

Usage & Features

oogradient "Hello World"                        # Apply default rainbow TrueColor gradient
oogradient -p cyberpunk "Neon Grid City"        # Apply cyberpunk multi-stop palette
oogradient --from "#ff007f" --to "#00ffff" "Sky" # Custom hex color endpoints
oogradient --presets                           # List all registered gradient palettes
oogradient -j -p sunset "Telemetry Text"       # Structured JSON metric output
oogradient -D                                  # Interactive visual gradient showcase
oogradient --mcp                               # Launch Model Context Protocol stdio server
