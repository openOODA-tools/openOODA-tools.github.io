oogrep

Capability-bounded recursive regex search for the openOODA era.

v0.3.0 100% openOODA 85 self-checks green 48/48 vs GNU grep

Install

curl -fsSL https://openooda-tools.github.io/oogrep/install.sh | bash

Zero dependencies. Verifies SHA-256, installs to /usr/local/bin (or ~/.local/bin).

Packages: .deb (apt) and .rpm (dnf) are attached to every GitHub release:

sudo apt install ./oogrep_0.3.0-1_amd64.deb   # Debian/Ubuntu
sudo dnf install ./oogrep-0.3.0-1.*.rpm       # Fedora/RHEL
