oogrepz(1) — Sovereign openOODA Compressed Stream Search Engine

Zero-copy streaming search across gzip, bzip2, xz, and zstd compressed archives.

100% openOODA Zero Ambient Authority Gzip · Bzip2 · XZ · Zstd Model Context Protocol

Why Sovereign oogrepz?

Dimension Legacy Tools (zgrep / zcat | grep shell scripts) openOODA oogrepz
ArchitectureShell wrapper invoking external uncompress utilities via ambient pipesPure native openOODA with explicit capability tokens (&FsReadCap, &ProcessCap, &EnvCap)
Container SupportFragmented tools (zgrep, bzgrep, xzgrep, zstdgrep) with inconsistent flagsUnified multi-container engine auto-detecting gzip, bzip2, xz, and zstd transparently
TelemetryRaw text stdout only without structured metricsPOSIX text formatting with ANSI color highlights plus structured JSON metrics (-j)
AI AgentsNo agent interface for archive stream inspectionStreaming MCP JSON-RPC 2.0 stdio server providing search, count, detect, files, and demo tools

Usage & Features

oogrepz "pattern" /var/log/syslog.gz            # Search single compressed archive
oogrepz -i -n "error" /var/log/*.gz             # Case-insensitive search with line numbers
oogrepz -c "fault" audit.log.xz                 # Count occurrences in xz archive
oogrepz -l "critical" *.zst                     # List matching zstd archive filenames
oogrepz -j "kernel" boot.log.bz2                # Structured JSON search metrics
oogrepz -D                                      # Interactive multi-archive search showcase
oogrepz --mcp                                   # Launch Model Context Protocol stdio server
