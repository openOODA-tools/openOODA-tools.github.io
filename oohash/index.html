Usage & Features

oohash file.iso                                  # Simultaneous BLAKE3, SHA-256, SHA3-512 table
oohash -a sha256 file.iso                        # Output SHA-256 in GNU format
oohash --tag -a sha3_512 file.iso                # Output BSD-style tag
oohash -r -a blake3 file.iso                     # Raw hexadecimal digest only
oohash -c manifest.txt                           # Universal manifest verification
oohash -j file.iso                               # Output structured JSON metrics
oohash -D                                        # Interactive cryptographic showcase demo
oohash --mcp                                     # Launch Model Context Protocol stdio server
