Why Sovereign oohistory?

Dimension Conventional bash / zsh history openOODA oohistory

Usage & Features

oohistory                                        # Display recent shell command history
oohistory -n 25                                  # Limit display to the last 25 records
oohistory -s docker                              # Filter history by keyword search
oohistory -a "export OPENAI_API_KEY=sk-..."      # Append record with automatic credential masking
oohistory --verify                               # Audit cryptographic hash chain integrity
oohistory --stats                                # Display command counts and security metrics
oohistory -j                                     # Structured JSON Lines output
oohistory -D                                     # Interactive secret masking & tamper simulation
oohistory --mcp                                  # Launch Model Context Protocol stdio server
