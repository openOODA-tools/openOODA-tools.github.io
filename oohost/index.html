oohost(1) — Sovereign openOODA DNS Host Resolver

Quick DNS address resolver performing forward and reverse host conversions with dual-surface parity.

100% openOODA Zero Ambient Authority Networking & Egress Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oohost/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oohost/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oohost/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oohost/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oohost binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oohost-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oohost/uninstall.sh | bash

Why Sovereign oohost?

Dimension Conventional BIND host openOODA oohost
AuthorityUnbounded ambient network and filesystem accessCapability-bounded (&FsReadCap, &ProcessCap, &EnvCap, &McpCap)
Reverse LookupsManual in-addr.arpa / ip6.arpa calculationsAutomatic IPv4 dotted-quad and IPv6 nibble PTR transformation
Output FormattingRigid text requiring custom sed/awk scriptsStandard BIND format, terse raw address mode (-s), and JSON Lines (-j)
AI IntegrationNo structured agent interface for inspectionStreaming MCP JSON-RPC 2.0 stdio server providing 5 turnkey tools

Usage & Features

oohost example.com                               # Forward lookup for IPv4 and IPv6 addresses
oohost 93.184.215.14                             # Reverse lookup for IPv4 address (PTR record)
oohost -t mx example.com                         # Query specific mail exchange records
oohost -a example.com                            # Query all available DNS records (ANY)
oohost -s example.com                            # Terse pipeline output (emit only raw addresses)
oohost example.com 1.1.1.1                       # Query using custom upstream nameserver
oohost -v example.com                            # Verbose query diagnostics with response latency
oohost -j example.com                            # Structured JSON Lines telemetry
oohost -D                                        # Interactive DNS resolution showcase
oohost --mcp                                     # Launch Model Context Protocol stdio server
