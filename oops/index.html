oops

Process tree visualizer, systemd slice grouping, and signal manager with oote palettes and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority systemd Slices Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oops/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oops/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oops/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oops/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oops binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oops-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oops/uninstall.sh | bash

Usage & Features

oops                           # Flat process list with state badges
oops -T                        # Hierarchical process tree with branch glyphs
oops -c user.slice             # Filter processes by systemd slice
oops -k 1234 -s TERM           # Capability-gated SIGTERM signal dispatch
oops --mcp                     # Launch MCP stdio server
