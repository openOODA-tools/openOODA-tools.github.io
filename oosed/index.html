oosed

Capability-bounded stream editor and text transformer with safe atomic in-place edits and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority Atomic Writes Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oosed/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oosed/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oosed/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oosed/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oosed binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oosed-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oosed/uninstall.sh | bash

Why Sovereign oosed?

Dimension Conventional Alternatives openOODA oosed

AI AgentsNo agent interfaceMCP stdio tools: sed_substitute, sed_stream

Usage & Features

echo "hello world" | oosed 's/world/openOODA/g' # Stream substitution
oosed -i 's/foo/bar/g' config.txt # Safe atomic in-place edit
oosed -n '1,10p' document.txt  # Print line range
oosed --mcp                    # Launch MCP stdio server
