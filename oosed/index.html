oosed

Sovereign stream editor and capability-bounded text transformer with atomic in-place edits and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority Safe In-Place Edits Stream Pipeline Model Context Protocol

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/oosed/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/oosed/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/oosed/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/oosed/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove oosed binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
oosed-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/oosed/uninstall.sh | bash

# 3. Dry-run preview
oosed-uninstall --dry-run

Try it

echo "hello world" | oosed 's/world/openOODA/g'   # Stream substitution
oosed -i 's/foo/bar/g' config.txt                # Atomic capability-bounded edit
oosed -n '1,10p' document.txt                    # Print specific line range
oosed '/^#/d' config.ini                         # Strip comments
oosed --mcp                                      # Launch MCP stdio server
