oosh

Intent-driven, ambient, capability-bounded interactive shell for the openOODA era.

v0.9.0 100% openOODA 5 Threat Defenses POSIX Parity Clean Unthemed ANSI-16

Install

curl -fsSL https://openooda-tools.github.io/oosh/install.sh | bash

Zero dependencies. Standalone binary verified with cryptographic SHA-256 seal, installs to /usr/local/bin (or ~/.local/bin).

Try it

oosh                           # Enter interactive sovereign shell
oosh -c 'caps'                 # Audit active capability tokens
oosh -c 'whereami'             # Contextual location and git status
oosh -c '{ A=1; echo $A; } > out.txt' # In-process group redirection
oosh -c '? list largest files' # Natural language intent channel
