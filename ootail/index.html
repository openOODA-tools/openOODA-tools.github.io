ootail

Capability-bounded file tail and follower utility for the openOODA era.

v0.1.0 100% openOODA Zero Ambient Authority Inotify Watch Truncate Recovery

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/ootail/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/ootail/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/ootail/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/ootail/install.sh | bash -s -- --arch

Zero dependencies. Standalone native binary compiles directly against libc and installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove binary, packages (apt, dnf, pacman), companion tools, and caches:

# 1. Via companion CLI (situated automatically alongside ootail):
ootail-uninstall

# 2. Standalone web uninstaller:
curl -fsSL https://openooda-tools.github.io/ootail/uninstall.sh | bash

# 3. Via universal installer flag:
curl -fsSL https://openooda-tools.github.io/ootail/install.sh | bash -s -- --uninstall

# 4. Preview uninstallation without making changes (dry-run):
curl -fsSL https://openooda-tools.github.io/ootail/uninstall.sh | bash -s -- --dry-run

Try it

ootail -n 20 /var/log/syslog              # View last 20 lines
ootail -f app.log                         # Follow app logs with inotify
journalctl -u systemd-journald | ootail   # Stream from standard input
ootail -f /var/log/auth.log /var/log/syslog # Follow multiple files simultaneously
