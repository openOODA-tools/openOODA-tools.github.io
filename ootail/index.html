Capability-bounded streaming file and event follower with inotify tracking, truncate safety, and oote palettes.

Why Sovereign ootail?

Dimension Conventional Alternatives openOODA ootail
SecurityAmbient file handle trackingBounded by &FsReadCap and &SysCap
RotationStalls or fails on log rotateSeamless follow across truncation and rotation (-F)
ThemingRaw monochrome streamReal-time syntax and status token highlighting via oote
AI AgentsNo agent interfaceNative MCP stdio server (--mcp) with tail_file and tail_stream
WindowingLine-only or rigid buffersHigh-speed byte windowing (-c) and line offsets (+NUM)

Usage & Features

ootail -f /var/log/app.log     # Follow file stream with inotify events
ootail -n 50 system.journal    # Inspect trailing 50 lines
ootail -c 512 service.log      # Inspect trailing 512 bytes
ootail -n +100 app.log         # Emit lines starting from line 100
ootail --mcp                   # Run Model Context Protocol stdio server
