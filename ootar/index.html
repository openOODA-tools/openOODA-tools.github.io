Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/ootar/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/ootar/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/ootar/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/ootar/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove ootar binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
ootar-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/ootar/uninstall.sh | bash

# 3. Dry-run preview
ootar-uninstall --dry-run
