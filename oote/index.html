oote

Sovereign unified theming and color engine for the openOODA ecosystem.

v0.1.0 100% openOODA 25 Themes Dual Light / Dark Circadian & Calendar Auto ASCII Mascots

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/oote/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/oote/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/oote/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/oote/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove oote binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper (if already installed)
oote-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/oote/uninstall.sh | bash

# 3. Complete wipe (also removes ~/.openooda/theme.oot and cache)
oote-uninstall --purge
# or: curl -fsSL https://openooda-tools.github.io/oote/uninstall.sh | bash -s -- --purge

Try it

oote preview ember                     # Preview October theme
oote preview spooky                    # Preview Halloween holiday theme
oote list                              # List all 25 available themes
oote set auto                          # Enable dynamic calendar & circadian mode
oote mascot spooky happy               # Show mascot happy emotion
oote border double                     # Switch border frames to double lines
oote mode toggle                       # Toggle between light and dark mode
