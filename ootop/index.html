Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/ootop/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/ootop/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/ootop/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/ootop/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove ootop binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
ootop-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/ootop/uninstall.sh | bash

# 3. Dry-run preview
ootop-uninstall --dry-run
