ootop

Real-time system monitor with systemd slice resource aggregation, sparklines, and mascot telemetry.

v0.1.0 100% openOODA Zero Ambient Authority systemd Slices Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/ootop/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/ootop/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/ootop/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/ootop/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove ootop binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI ootop-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/ootop/uninstall.sh | bash
