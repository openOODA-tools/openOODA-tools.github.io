ootree

Sovereign directory hierarchy visualizer with branch glyphs, gitignore filtering, oote palettes, and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority oote Themes Branch Glyphs Model Context Protocol

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/ootree/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/ootree/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/ootree/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/ootree/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove ootree binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
ootree-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/ootree/uninstall.sh | bash

# 3. Dry-run preview
ootree-uninstall --dry-run

Try it

ootree                                 # Visualize current directory tree
ootree /path/to/project -L 2           # Limit recursion depth to 2 levels
ootree -d                              # Display directories only
ootree -s                              # Show human-readable file sizes
ootree --mcp                           # Launch MCP stdio server
