ootree

Directory hierarchy visualizer with Unicode branch glyphs, gitignore filtering, oote palettes, and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority Unicode Glyphs Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/ootree/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/ootree/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/ootree/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/ootree/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove ootree binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI ootree-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/ootree/uninstall.sh | bash

Usage & Features

ootree                         # Visualize current directory tree
ootree /path/to/project -L 2   # Limit recursion depth to 2 levels
ootree -d                      # Display directories only
ootree -s                      # Show human-readable file sizes
ootree --mcp                   # Launch MCP stdio server
