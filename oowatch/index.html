oowatch

Sovereign continuous command scheduler and delta watcher with ANSI diff highlighting, oote palettes, and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority ANSI Delta Diffs oote Themes Model Context Protocol

Install

Universal Standalone:

curl -fsSL https://openooda-tools.github.io/oowatch/install.sh | bash

DNF (Fedora / RHEL / CentOS):

curl -fsSL https://openooda-tools.github.io/oowatch/install.sh | bash -s -- --dnf

DEB (Debian / Ubuntu):

curl -fsSL https://openooda-tools.github.io/oowatch/install.sh | bash -s -- --deb

PKGBUILD (Arch Linux / Manjaro):

curl -fsSL https://openooda-tools.github.io/oowatch/install.sh | bash -s -- --pkgbuild

Zero dependencies. Standalone binary installs to /usr/local/bin (or ~/.local/bin). Native .deb, .rpm, and PKGBUILD packages are also available directly on GitHub Releases.

Uninstall

Cleanly remove oowatch binaries, packages, and helper scripts at any time:

# 1. Via installed CLI helper
oowatch-uninstall

# 2. Via dedicated web uninstaller
curl -fsSL https://openooda-tools.github.io/oowatch/uninstall.sh | bash

# 3. Dry-run preview
oowatch-uninstall --dry-run

Try it

oowatch uptime                         # Run command every 2 seconds
oowatch -n 1 -d free -m                # 1s refresh interval with delta diffs
oowatch -t date                        # Suppress header banner
oowatch -c 5 -n 1 ps aux               # Run 5 iterations and exit
oowatch --mcp                          # Launch MCP stdio server
