oowatch

Continuous command scheduler and delta watcher with ANSI diff highlighting, oote palettes, and MCP surface.

v0.1.0 100% openOODA Zero Ambient Authority ANSI Delta Diffs Model Context Protocol

Install

Universal Standalone Binary:

curl -fsSL https://openooda-tools.github.io/oowatch/install.sh | bash

Native Package Managers (Tri-Distribution Parity)

# Fedora / RHEL / CentOS (DNF) curl -fsSL https://openooda-tools.github.io/oowatch/install.sh | bash -s -- --dnf
# Ubuntu / Debian (APT) curl -fsSL https://openooda-tools.github.io/oowatch/install.sh | bash -s -- --deb
# Arch Linux / Manjaro (Pacman / PKGBUILD) curl -fsSL https://openooda-tools.github.io/oowatch/install.sh | bash -s -- --pkgbuild

Clean Uninstallation

Remove oowatch binaries, package registrations, and symlinks at any time:

# Locally installed companion CLI oowatch-uninstall # Standalone web uninstaller curl -fsSL https://openooda-tools.github.io/oowatch/uninstall.sh | bash

Usage & Features

oowatch uptime                 # Run command every 2 seconds
oowatch -n 1 -d free -m        # 1s refresh interval with delta diffs
oowatch -t date                # Suppress header banner
oowatch -c 5 -n 1 ps aux       # Run 5 iterations and exit
oowatch --mcp                  # Launch MCP stdio server
